# Simple KPI Tracking Sheet

## Project Overview
This project focuses on building a simple KPI tracking dashboard using Microsoft Excel and the Sample Superstore dataset. The dashboard summarizes key sales metrics to support quick business analysis.

## Objectives
- Calculate total revenue.
- Calculate total units sold.
- Calculate average order value.
- Identify the top-performing product by sales.

## Tools Used
- Microsoft Excel
- Sample Superstore Dataset
- Excel Tables, formulas, and PivotTables

## Key Performance Indicators
- **Total Revenue:** Sum of all sales.
- **Units Sold:** Total quantity sold.
- **Average Order Value:** Sales divided by the number of order records.
- **Top Product:** Product with the highest total sales.

## Project Structure
- `Simple_KPI_Tracking.xlsx` – Excel workbook containing the raw data, KPI summary, and top-product analysis.
- `README.md` – Project documentation.

## Features
- Single-sheet KPI summary dashboard.
- Formula-based calculations.
- Excel Table for easier data management and expansion.
- PivotTable analysis to identify the top product.

## Outcome
Developed a compact sales KPI dashboard that converts raw transactional data into useful business metrics.
